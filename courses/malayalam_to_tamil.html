മലയാളത്തിൽ നിന്ന് தமிழ்

സഹോദരഭാഷയുടെ പാലം — പത്തു പടികളിൽ தமிழ் പഠിക്കാം
STAGE 00

പരിചയം — അറിയാവുന്നതും പുതിയതും

മലയാളം പഴയ തമിഴിൽ നിന്നു പിരിഞ്ഞ കുഞ്ഞാണ്. രണ്ടു ഭാഷകളുടെയും അമ്മ ഒന്നുതന്നെ — പ്രാചീന ദ്രാവിഡം. അതിനാൽ നിങ്ങൾ தமிழ் പഠിക്കാൻ തുടങ്ങുമ്പോൾ, അന്യഭാഷ പഠിക്കുകയല്ല, മറന്നുപോയ പഴയ കുടുംബവീട്ടിലേക്കു തിരിച്ചുപോവുകയാണ്.

കുട്ടിക്കാലത്ത് "സ്വരവും വ്യഞ്ജനവും" എന്ന വരികളിൽ അ–ആ–ഇ–ഈ ചൊല്ലിപ്പഠിച്ചപ്പോൾ, അതേ ക്രമത്തിൽ തമിഴർ அ–ஆ–இ–ஈ എന്നും ചൊല്ലുകയായിരുന്നു — അക്ഷരങ്ങളുടെ രൂപം മാത്രം വേറേ. 33 ശബ്ദങ്ങളിൽ 31 എണ്ണവും പൊതു. വാക്യഘടന ഒന്നുതന്നെ (കർത്താവ്–കർമ്മം–ക്രിയ). പദാവലിയുടെ 70 ശതമാനത്തിലേറെ പങ്കുവെക്കുന്നു.

ഒരു ലളിതവാക്യം നോക്കൂ:
മലയാളം — ഞാൻ വെള്ളം കുടിക്കുന്നു
തമിഴ് — நான் தண்ணீர் குடிக்கிறேன் (nāṉ taṇṇīr kuḍikkiṟēṉ)
വാക്കിന്റെ ക്രമം അതുതന്നെ. "ഞാൻ" — "நான்". "കുടി" — "குடி". വ്യത്യാസം ക്രിയാപദത്തിലെ ലിംഗബോധത്തിലും ചില്ലക്ഷരങ്ങളുടെ അസാന്നിധ്യത്തിലും മാത്രം.

ആറു തത്ത്വങ്ങൾ

  1. ലിപിയുടെ രൂപം മാറി, യുക്തി മാറിയില്ല. രണ്ടും അബുഗിഡ — അക്ഷരത്തിൽ സ്വരം ഉൾച്ചേർന്നു നിൽക്കും; ചിഹ്നം ചേർത്താൽ മറ്റു സ്വരം വരും. ക + ാ = കാ എന്നതുപോലെ க + ா = கா. ചന്ദ്രക്കല ( ്) തമിഴിൽ പുള്ളി ( ்).
  2. 31/33 ശബ്ദങ്ങൾ ഒത്തവ. നിങ്ങളുടെ നാവിനു പരിചയമുള്ള ശബ്ദങ്ങൾ തന്നെ. க, ச, ட, த, ப, ம, ந, ர, ல, வ, ய, ள, ழ — എല്ലാം മലയാളത്തിൽ ഉള്ളവ.
  3. ഴ — രണ്ടു ഭാഷകളും മാത്രം പങ്കിടുന്ന അത്ഭുതധ്വനി. മലയാളത്തിലെ ഴ (മഴ, വാഴ) തന്നെ തമിഴിലെ ழ (மழை, வாழை). ഇന്ത്യയിലെ മറ്റൊരു വലിയ ഭാഷയിലും ഈ ശബ്ദമില്ല — കന്നടയിലും തെലുഗുവിലും പോലുമില്ല.
  4. തമിഴിന്റെ വ്യഞ്ജനശേഖരം ചെറുത്. മലയാളത്തിൽ ഖ–ഘ, ഗ–ഗ്‌ഹ, ജ–ഝ എന്നീ മഹാപ്രാണ/ഘോഷ വ്യത്യാസങ്ങൾ ഉണ്ട്; തമിഴിനു ഒരേ க മാത്രം — സ്ഥാനമനുസരിച്ച് ക, ഗ, ഹ എന്നിങ്ങനെ ഉച്ചരിക്കും. பகல் = പകൽ, தங்கம் = തങ്കം.
  5. സംസ്കൃതച്ചായ്‌വിൽ വ്യത്യാസം. മലയാളം തത്സമ പദങ്ങൾ (ഭൂമി, സൂര്യൻ, സമയം) സ്വാഭാവികമായി ഉപയോഗിക്കുന്നു; തമിഴ് കഴിയുന്നിടത്തെല്ലാം ശുദ്ധ ദ്രാവിഡരൂപം (நேரம், கதிரவன், நிலம்) ഇഷ്ടപ്പെടുന്നു.
  6. ലിംഗം — പുതിയ ശീലം. മലയാളത്തിൽ ക്രിയാപദത്തിനു ലിംഗമില്ല ("അവൻ ചെയ്യുന്നു" / "അവൾ ചെയ്യുന്നു" — ഒരേ ചെയ്യുന്നു). തമിഴിൽ ക്രിയ തന്നെ മാറും: அவன் செய்கிறான் / அவள் செய்கிறாள் / அது செய்கிறது. ഇതു പുതുതായി ശീലിക്കേണ്ടത്.
ഏറ്റവും അടുത്ത സഹോദരി. ഇന്ത്യൻ ഭാഷകളിൽ മലയാളത്തിന്റെ ഏറ്റവും അടുത്ത ബന്ധം തമിഴുമായാണ് — കന്നടയോടോ തെലുഗുവിനോടോ അല്ല. ഏകദേശം ഒൻപതാം–പത്താം നൂറ്റാണ്ടുവരെ ഇവ രണ്ടും ഒരു ഭാഷയുടെ രണ്ടു നാടൻപേരുകൾ മാത്രമായിരുന്നു.
STAGE 01

സ്വരം — അ ആ ഇ ഈ

മലയാളത്തിലെ സ്വരക്രമം അതേ പടി തമിഴിലുമുണ്ട്. രൂപങ്ങൾ മാത്രം പുതിയത്. തമിഴിൽ സ്വരങ്ങളെ உயிர் எழுத்து (ഉയിർ എഴുത്ത് — "ജീവനുള്ള അക്ഷരം") എന്നു വിളിക്കും.

'അ' കുടുംബം — ഹ്രസ്വവും ദീർഘവും

அഅaമലയാളം "അമ്മ" → തമിഴ് "அம்மா" — ഹ്രസ്വം, ഒരേ ശബ്ദം.
ஆആaːമലയാളം "ആന" → തമിഴ് "ஆனை". ദീർഘം, ഒരേ ശബ്ദം.

'ഇ' കുടുംബം

இഇi"ഇല" → "இலை" (ഇലൈ).
ஈഈiː"ഈ" (ഈച്ച) → "ஈ" — അക്ഷരവും അർത്ഥവും ഒന്നുതന്നെ!

'ഉ' കുടുംബം

உഉu"ഉണ്ണി" → "உண்" (ഉൺ — ഭക്ഷിക്കുക).
ஊഊuː"ഊര്" (ഗ്രാമം) → "ஊர்" — അക്ഷരവും അർത്ഥവും കൃത്യം!

'എ' കുടുംബം + ഐ

எഎe"എന്ത്" → "என்ன" (എന്ന — എന്ത്).
ஏഏeː"ഏഴ്" → "ஏழு" (ഏഴു — ഏഴ്).
ஐഐai"ഐരാവതം" → "ஐம்பது" (അമ്പത്).

'ഒ' കുടുംബം + ഔ

ஒഒo"ഒന്ന്" → "ஒன்று" (ഒൻറു — ഒന്ന്).
ஓഓoː"ഓടുക" → "ஓடு" (ഓടു).
ஔഔauസംസ്കൃതവാക്കുകളിൽ മാത്രം.
പങ്കുവെക്കുന്ന പൊരുൾ. മുകളിൽ കണ്ട പല കാർഡുകളിലും — ஈ, ஊர், ஏழு, ஒன்று — അക്ഷരവും വാക്കും അർത്ഥവും ഒരേ പോലെ! ഇതു യാദൃച്ഛികമല്ല; രണ്ടു ഭാഷകളും ഒരേ അമ്മയുടെ മക്കൾ എന്നതിന്റെ തെളിവ്.
ചെറുത് ഒന്നുമില്ല. മലയാളത്തിൽ ഋ (കൃഷ്ണൻ) സംസ്കൃതപദങ്ങളിൽ വരും. തമിഴിൽ ഈ സ്വരമില്ല — கிருஷ்ணன் എന്ന് കി-രി എന്ന രണ്ടക്ഷരമാക്കി എഴുതും. ഇതു തമിഴ് തത്സമ കുറച്ചതിന്റെ ലക്ഷണം.
തമിഴ് സ്വരങ്ങളുടെ ഉച്ചാരണം — കൂടുതൽ തിരയുക ↗
STAGE 02

വ്യഞ്ജനം — മെയ് എഴുത്ത്

തമിഴിൽ വ്യഞ്ജനങ്ങളെ மெய் எழுத்து (മെയ് എഴുത്ത് — "ശരീരാക്ഷരം") എന്നു വിളിക്കും. 18 അടിസ്ഥാന വ്യഞ്ജനങ്ങൾ മാത്രം — മലയാളത്തിലെ 36-നെ അപേക്ഷിച്ച് പാതിയിലും കുറവ്. കാരണം: തമിഴ് ഒരേ അക്ഷരം കൊണ്ട് ക, ഗ, ഹ എന്നിവയെല്ലാം എഴുതും — സ്ഥാനം നോക്കി ഉച്ചരിക്കും.

കണ്ഠ്യവർഗം ("ക" വർഗം)

கക / ഖ / ഗ / ഘkaമലയാളത്തിലെ നാലു രൂപങ്ങൾ ഒന്നിലേക്കു ചുരുങ്ങി. கதை=കഥൈ, பகல்=പഗൽ, அங்கே=അങ്ങെ.
ஙങṅaഅതേ അനുനാസികം — அங்கே = അങ്ങെ.

താലവ്യവർഗം ("ച" വർഗം)

சച / ഛ / ജ / ഝ / ശcaപദാദിയിൽ "സ", മധ്യത്തിൽ "ച", "ശ" എന്നും ഉച്ചരിക്കും. சரி=സരി, அச்சம்=അച്ചം.
ஞഞñaഅതേ ശബ്ദം — ஞாயிறு = ഞായിറു (ഞായർ).

മൂർധന്യവർഗം ("ട" വർഗം)

டട / ഠ / ഡ / ഢṭaഎല്ലാം ഒന്നായി. கட்டை=കട്ടൈ, மாடு=മാടു.
ணണṇaഅതേ ശബ്ദം — கண் = കൺ (കണ്ണ്).

ദന്ത്യവർഗം ("ത" വർഗം)

தത / ഥ / ദ / ധtaനാലു രൂപം ഒന്നിലേക്കു. தங்கம்=തങ്കം, பாதம்=പാദം.
நനnaപദാദിയിൽ ഈ അക്ഷരം — நான் = ഞാൻ.

ഓഷ്ഠ്യവർഗം ("പ" വർഗം)

பപ / ഫ / ബ / ഭpaനാലു രൂപങ്ങൾ ഒന്നിൽ. பால்=പാൽ, அபாயம்=അബായം.
மമmaഅതേ ശബ്ദം — மரம் = മരം.

ளളḷaഅതേ മൂർധന്യ-ള — அள்ளி=അള്ളി.
ற— (പുതുത്)ṟaമലയാളം ഉപേക്ഷിച്ച പഴയ ദ്രാവിഡ "റ". നാക്കിന്റെ അറ്റം മുകളിലെ പല്ലിന്റെ പിൻഭാഗത്തു തട്ടി വരും. ஆறு=ആറു (നദി/ആറ്).
ன— (പുതുത്)ṉaഅൽവിയോളാർ "ന" — நான்=ഞാൻ. എഴുത്തിൽ ந (പദാദി) vs ன (അല്ലാത്തിടത്തെല്ലാം) എന്ന വേർതിരിവ് മലയാളത്തിൽ ഇല്ല.
ചെറിയ കൂട്, വലിയ കൃത്യത. തമിഴിനു 18 വ്യഞ്ജനങ്ങൾ; മലയാളത്തിനു 36. തമിഴ് ക/ഗ/ഹ വേർതിരിക്കാത്തത് ദരിദ്രത്വമല്ല — പ്രാചീന ദ്രാവിഡ സ്വഭാവം അതാണ്. സംസ്കൃതം വന്നപ്പോൾ മലയാളം പുതിയ അക്ഷരങ്ങൾ എടുത്തു, തമിഴ് സ്വയം ഭംഗിയിൽ നിലകൊണ്ടു.
ചില്ലക്ഷരം ഇല്ല. മലയാളത്തിലെ ൻ, ർ, ൽ, ൾ, ൺ — ഇവ തമിഴിൽ സ്വതന്ത്ര ചിഹ്നമായി ഇല്ല. പകരം ன், ர், ல், ள், ண் എന്നു പുള്ളിയിട്ടു എഴുതും. அவன் = അവൻ.

സംയോജനം — അക്ഷരം പണിയുന്ന വിധം

STAGE 05

വാക്യം — ഘടനയും ക്രിയയും

വാക്യക്രമം ഒന്നുതന്നെ: കർത്താവ്–കർമ്മം–ക്രിയ. വിഭക്തിപ്രത്യയങ്ങൾ (ഉത്തരാന്വയം) ഇരു ഭാഷയിലും സമാനം. പുതിയത് ഒന്നുമാത്രം — ക്രിയയിലെ ലിംഗവിവേചനം.

ഒന്ന് — സ്വയം പരിചയപ്പെടുത്തൽ

என் பெயர் ராஜன். நான் கேரளத்தில் இருந்து வருகிறேன். எனக்கு தமிழ் பிடிக்கும். நான் தினமும் தமிழ் கற்றுக்கொள்கிறேன். என் வீடு திருவனந்தபுரத்தில் இருக்கிறது.

എന്റെ പേര് രാജൻ. ഞാൻ കേരളത്തിൽ നിന്ന് വരുന്നു. എനിക്ക് തമിഴ് ഇഷ്ടമാണ്. ഞാൻ ദിവസവും തമിഴ് പഠിക്കുന്നു. എന്റെ വീട് തിരുവനന്തപുരത്താണ്.

രണ്ട് — ദിവസചര്യ

நான் காலையில் ஆறு மணிக்கு எழுந்திருக்கிறேன். பிறகு காபி குடிக்கிறேன். எட்டு மணிக்கு அலுவலகம் போகிறேன். மதியம் சாப்பிடுகிறேன். மாலையில் வீட்டுக்கு வருகிறேன். இரவு புத்தகம் படிக்கிறேன்.
nāṉ kālaiyil āṟu maṇikku eḻuntirukkiṟēṉ. piṟaku kāpi kuḍikkiṟēṉ. eṭṭu maṇikku aluvalakam pōkiṟēṉ. madiyam sāppiḍukiṟēṉ. mālaiyil vīṭṭukku varukiṟēṉ. iravu puttakam paḍikkiṟēṉ.
ഞാൻ രാവിലെ ആറ് മണിക്ക് എഴുന്നേൽക്കുന്നു. പിന്നെ കാപ്പി കുടിക്കുന്നു. എട്ട് മണിക്ക് ഓഫീസിലേക്ക് പോകുന്നു. ഉച്ചയ്ക്ക് ഊണ് കഴിക്കുന്നു. വൈകുന്നേരം വീട്ടിലേക്ക് വരുന്നു. രാത്രി പുസ്തകം വായിക്കുന്നു.

கலா: ஆமாம், சாப்பிட்டேன். நீங்க எங்கே போறீங்க?

സാപ്പിട്ടീങ്കളാ? — കേരളത്തിലും കേട്ടിട്ടുണ്ട്. ഊണു കഴിച്ചോ എന്നു ചോദിക്കുന്നത് സ്നേഹത്തിന്റെ വിളിയാണ്; ഭക്ഷണശാസ്ത്രമല്ല. തമിഴരുടെ "சாப்பிட்டீங்களா?" മലയാളിയുടെ "ഉണ്ടോ?" — ഒരേ സാംസ്കാരിക അർത്ഥം.
STAGE 07

പദമേഖല — ബന്ധുത്വം, കാലം, ശരീരം

ബന്ധുത്വം

STAGE 08

ഉപയോഗം — മര്യാദയും സംഭാഷണവും

മൂന്നുതല ബഹുമാനരീതി

തലംതമിഴ്മലയാളംസന്ദർഭം
അടുപ്പംநீനീകുട്ടി, അടുത്ത സുഹൃത്ത്

മൃദുലപദങ്ങൾ

கொஞ்சம் (koñcam) = "കുറച്ച്". അഭ്യർത്ഥന മൃദുവാക്കുന്നു. "கொஞ்சம் தண்ணீர் கொடுங்க" = "കുറച്ച് വെള്ളം തരൂ". മലയാളത്തിലെ "കുറച്ച്", കന്നടയിലെ "സ്വൽപ", ബംഗാളിയിലെ "ഏകടു" — ഒരേ ധർമ്മം.

സൗഹൃദപരമായ കുടുംബപദ്ധതി. രണ്ടു ഭാഷയിലും — അറിയാത്തവരെ കുടുംബാംഗമെന്നപോലെ വിളിക്കുന്നത് — ദ്രാവിഡ സംസ്കാരത്തിന്റെ പൊതു സ്വഭാവം. "സർ" "മാഡം" എന്ന ദൂരമില്ല; ചേട്ടൻ/அண்ணா എന്ന അടുപ്പം.
STAGE 09

സാഹിത്യം — പാലങ്ങൾ

തമിഴ് സാഹിത്യത്തിന്റെ പാരമ്പര്യം 2300 വർഷം പഴക്കമുള്ളത് — ലോകത്തിലെ ജീവനുള്ള ശാസ്ത്രീയ ഭാഷകളിൽ ഏറ്റവും പഴക്കമുള്ളത്. സംഘം സാഹിത്യത്തിൽ നിന്നു തുടങ്ങി ആധുനിക നോവൽ വരെ. മലയാള സാഹിത്യം ഈ വേരിൽ നിന്ന് വളർന്നതാണ്.

ഏഴു പാലങ്ങൾ

திருவள்ளுவர் — തിരുവള്ളുവർ (~ ക്രി.മു. 3-ാം നൂറ്റാണ്ട്)

തിരുക്കുറൾ — 1330 ഈരടികൾ; ധർമ്മം, അർത്ഥം, കാമം. മതമല്ല, മാനവിക ധർമ്മശാസ്ത്രം. മലയാളി എഴുത്തച്ഛൻ ആദ്ധ്യാത്മരാമായണം കിളിപ്പാട്ട്-ൽ തിരുവള്ളുവരുടെ ഈരടി-ശൈലിക്ക് സമാനമായ ഒതുക്കവും ഗാംഭീര്യവും കൊണ്ടുവരാൻ ശ്രമിച്ചു. രണ്ടുപേരും ഭാഷയെ പ്രസാദത്തിലേക്കു നയിച്ച മഹാഗുരുക്കൾ.

கம்பன் — കമ്പൻ (~ 12-ാം നൂറ്റാണ്ട്)

കമ്പരാമായണം. തമിഴിന്റെ ആ മഹാകാവ്യം മലയാളത്തിൽ തുഞ്ചത്ത് എഴുത്തച്ഛൻ അധ്യാത്മരാമായണം കിളിപ്പാട്ടിലൂടെ പുനരാവിഷ്കരിച്ചു. കമ്പന്റെ സംസ്കൃത-ദ്രാവിഡ സങ്കലനം എഴുത്തച്ഛൻ മലയാളത്തിൽ ശുദ്ധീകരിച്ചു — രണ്ടുപേരും സ്വന്തം ഭാഷയെ "സാഹിത്യഭാഷ" ആക്കിയവർ.

சுப்பிரமணிய பாரதி — സുബ്രഹ്മണ്യ ഭാരതി (1882–1921)

നവോത്ഥാന കവി; സ്വാതന്ത്ര്യഗായകൻ. "காக்கை குருவி எங்கள் சாதி" — വർണവ്യവസ്ഥയെ ചോദ്യം ചെയ്ത വാക്ക്. മലയാളത്തിലെ കുമാരനാശാൻ-ന് ഭാരതി നേരിട്ടുള്ള സമകാലികൻ. "ചണ്ഡാലഭിക്ഷുകി"യും "വീണപൂവും" എഴുതിയ ആശാന്റെ സാമൂഹിക ഉൾക്കാഴ്ചയുമായി ഭാരതിയുടെ സാഹോദര്യകാവ്യം ഒത്തുചേരുന്നു.

புதுமைப்பித்தன் — പുതുമൈപ്പിത്തൻ (1906–1948)

തമിഴ് ചെറുകഥയുടെ പിതാവ്; ഇരുണ്ട റിയലിസം, നഗരദു:ഖം. മലയാളത്തിലെ വൈക്കം മുഹമ്മദ് ബഷീർ ഈ കാലത്ത് തന്നെ സാധാരണ മനുഷ്യരുടെ ഭാഷയിൽ എഴുതി — "ബാല്യകാലസഖി", "പാത്തുമ്മയുടെ ആട്". രണ്ടുപേരും സാഹിത്യത്തെ സംസ്കൃത ഭാരത്തിൽ നിന്നു മുക്തമാക്കി, തെരുവിന്റെ ശ്വാസം എഴുത്തിൽ കൊണ്ടുവന്നു.

ஜெயகாந்தன் — ജയകാന്തൻ (1934–2015)

ജ്ഞാനപീഠം. നഗര റിയലിസം; വേശ്യ, തൊഴിലാളി, അധഃസ്ഥിതൻ — സാഹിത്യത്തിലെ അവരുടെ സ്ഥാനം ഉറപ്പിച്ചു. മലയാളത്തിലെ തകഴി ശിവശങ്കരപ്പിള്ള — "ചെമ്മീൻ", "രണ്ടിടങ്ങഴി" — മത്സ്യത്തൊഴിലാളിയുടെയും കർഷകന്റെയും ജീവിതം സാഹിത്യത്തിലേക്കു കൊണ്ടുവന്നു. രണ്ടുപേരുടെയും പ്രമേയം ഒന്നുതന്നെ — അധികാരശ്രേണിയുടെ അടിയിലെ മനുഷ്യൻ.

சுந்தர ராமசாமி — സുന്ദര രാമസ്വാമി (1931–2005)

"ஜே.ஜே: சில குறிப்புகள்" — ആധുനികോത്തര തമിഴ് സാഹിത്യത്തിന്റെ അടിസ്ഥാനകൃതി; ശൈലിയും ഘടനയും പുതുക്കി. മലയാളത്തിലെ ഒ.വി. വിജയൻ "ഖസാക്കിന്റെ ഇതിഹാസം" — അതേ തലമുറയിൽ അതേ ലക്ഷ്യത്തോടെ എഴുതപ്പെട്ടത്. രണ്ടു കൃതികളും തെക്കൻ സാഹിത്യത്തിനു നവീനതയുടെ വാതിൽ തുറന്നു.

സമകാലികർ — മറ്റൊരു പാലം

തമിഴിലെ அசோகமித்திரன் (അശോകമിത്രൻ) — നഗര ഇടത്തരക്കാരുടെ ഏകാന്തത. മലയാളത്തിലെ എം.ടി. വാസുദേവൻ നായർ — നാലുകെട്ടിലെ ഏകാന്തത. രണ്ടുപേരും സാവധാനത്തിലുള്ള, മൗനത്തിന്റെ ഭാരമുള്ള ഗദ്യം കെട്ടിപ്പടുത്തവർ.

സാഹിത്യത്തിന്റെ പങ്കുവെപ്പ്. തമിഴ് സംഘം സാഹിത്യത്തിലെ அகம் (അകം — അന്തരംഗം) / புறம் (പുറം — ബാഹ്യം) എന്ന വിഭജനം മലയാള ക്ലാസിക്കൽ കവിതയുടെ അടിയിലും ഒഴുകുന്നു. നിങ്ങൾ തമിഴ് വായിക്കുമ്പോൾ, മലയാളത്തിന്റെ വേരുകൾ സ്പർശിക്കുകയാണ്.
അഭിനന്ദനം. ഇവിടെ വരെ എത്തിയല്ലോ. தமிழ் ഇനി അന്യഭാഷയല്ല — നഷ്ടപ്പെട്ടുപോയ ഒരു ബന്ധു മാത്രം. நன்றி, வணக்கம்!
